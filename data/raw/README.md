# Kaggle Customer Support on Twitter

MANUAL STEP REQUIRED

1. Open https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter
2. Download the dataset (you need a free Kaggle account).
3. Unzip and copy `twcs.csv` here.

A subsample is expected. You can also keep a smaller file named `sample.csv` in this folder.

Do not commit the full CSV; it is large (~500MB+).

If you have the Kaggle CLI:

```
kaggle datasets download -d thoughtvector/customer-support-on-twitter -p data/raw
```

Then unzip `customer-support-on-twitter.zip` in this folder.
